================================================================
  Dola Pool 桌面版 · 快速开始
================================================================

一、怎么打开
----------------------------------------------------------------
Windows ：双击  start-windows.bat
macOS   ：双击  start-macos.command
          （若提示"无法打开，因为来自身份不明的开发者"，
            右键 → 打开 → 再点"打开"即可）
Linux   ：终端执行  ./start-linux.sh

首次启动会自动创建运行环境并安装依赖，大约 1-3 分钟；
之后每次启动只需几秒。

前提：电脑上要有 Python 3.10 或更高版本
      下载：https://www.python.org/downloads/
      Windows 安装时务必勾选 "Add Python to PATH"

程序默认是【演示模式】：不联网、不需要账号，任务会在 6 秒左右
生成一段内置示例视频，用来先把整个流程跑通、熟悉界面。


二、要生成真实视频（生产模式）
----------------------------------------------------------------
1. 打开界面 → 左侧【设置】→ 找到「桌面应用」卡片
2. 点【切换到生产模式】→ 窗口会自动重启（几秒钟）
3. 左侧【账号池】→【批量导入】→ 粘贴你的 Dola 账号 Cookie
   （每行一个，或拖入 .txt / .csv / .json 文件）
4. 左侧【生成】→ 填提示词 → 【提交任务】

注意：生产模式会真实调用 Dola 生成，需要账号自身有可用额度；
      生成逻辑与原始仓库完全一致（含代理轮换与去水印），
      我没有做任何改动。账号与风控风险请自行判断。


三、生成好的视频在哪里
----------------------------------------------------------------
· 界面【任务队列】里点【▶ 播放】可以直接看，弹窗里有
  【📂 打开所在文件夹】和【⬇ 下载】
· 文件保存在（各平台不同）：
    Windows  %APPDATA%\DolaPool\output
    macOS    ~/Library/Application Support/DolaPool/output
    Linux    ~/.local/share/dola-pool/output
· 界面【设置 → 桌面应用】里也有【📂 成片目录】按钮，一键定位


四、常用参数（可选）
----------------------------------------------------------------
命令行运行时可加参数：
    --no-demo        直接以生产模式启动
    --demo           强制演示模式
    --browser        不开原生窗口，用系统默认浏览器打开
    --port 8123      指定端口（默认自动选空闲端口）

例： start-windows.bat --no-demo


五、想做成免安装的 .exe / .app（可选）
----------------------------------------------------------------
说明：dist\DolaPool\ 不是仓库里自带的东西，而是【运行打包命令后现场生成】的
      输出目录（已被 .gitignore 排除，所以仓库里永远看不到它）。
      不打包也完全能用 —— 直接双击 start-windows.bat 就够了，
      只是那种方式要求电脑上装了 Python。

想拿到"别人电脑上不装 Python 也能跑"的程序，两种做法：

【方式一】在自己电脑上打包（需要装一次 Python + PyInstaller）
    pip install -r requirements-desktop.txt pyinstaller
    python tools/build_desktop.py
  执行完成后，打包脚本会打印产物路径，形如：
    Windows  仓库目录\dist\DolaPool\DolaPool.exe
    macOS    仓库目录/dist/DolaPool.app
    Linux    仓库目录/dist/DolaPool/DolaPool
  把整个 DolaPool 文件夹拷给别人，双击即可运行。
  注意 PyInstaller 不能跨平台：Windows 的 exe 必须在 Windows 上打。

【方式二】用 GitHub 云端打包（本机什么都不用装）
    1. 把仓库推到 GitHub（仓库里已带 .github/workflows/build-desktop.yml）
    2. 打开仓库 → Actions → 选 "Build Desktop App" → Run workflow
    3. 跑完后在该次运行页面底部 Artifacts 里下载 DolaPool-Windows，
       解压就是我们给你打好的 DolaPool\DolaPool.exe
    打 tag（如 v2.0.0）推送时还会自动建 Release，三平台产物都挂上去。


六、出问题了怎么办
----------------------------------------------------------------
· 提示没有 Python        → 装 Python 3.10+ 并勾选 Add to PATH
· 提示 GTK/QT 加载失败    → Linux 缺 GUI 库，用 --browser 参数先跑起来
                           或 sudo apt install python3-gi gir1.2-webkit2-4.1
· 任务一直是"失败"        → 检查【账号池】里有没有导入可用 Cookie
· 想要更多说明            → 见 README.md
